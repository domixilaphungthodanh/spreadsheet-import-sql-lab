# Năm bài tập

1. Đếm phiếu sau lần nhập đầu.
2. Tìm trạng thái SC-002 sau lần hai.
3. Đổi lượt nhập thành mã viết thường và thêm khoảng trắng rồi chạy lại.
4. Đổi ngày ở dòng cuối file lỗi thành ngày hợp lệ và nhập vào database thực hành.
5. Tạo file có hai mã trùng sau chuẩn hóa. Dự đoán số phiếu còn lại.
